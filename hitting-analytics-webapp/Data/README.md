# Data Directory

This directory contains data files for the Hitting Analytics application.

## Structure

- `raw/` - Raw data files from MLB
- `processed/` - Processed and cleaned data
- `cache/` - Cached data for faster loading

## Data Sources

Data is sourced from:
- MLB official statistics
- Baseball Reference
- MLB API

## File Formats

- CSV files for tabular data
- JSON files for hierarchical data
- Parquet files for efficient storage
